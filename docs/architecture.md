# 架构与一致性约束

## 模块

```text
CLI / FastAPI
      ↓
StoryService ──→ ResponsesModel ──→ POST /responses
      ↓
Repository ──→ SQLite（版本、运行、规划、正文）
      ↑
context.py：从已采纳正文回放记忆并选择上下文
```

`models.py` 定义输入与输出契约；`prompts.py` 定义分工；`config.py` 只在入口加载环境变量。密钥不会进入数据库、API 返回或运行日志。模型调用错误不会暴露提供商响应体。

## 数据层

| 表 | 职责 |
| --- | --- |
| `books` | 用户创意、作品设定、当前阶段、乐观锁版本 |
| `stages` | 任意编号的阶段目标、地图、验收标准和结束章节 |
| `plans` | 按书籍和章节唯一的未来规划 |
| `chapters` | 当前采纳的正文、审核和版本号 |
| `revisions` | 每次采纳的正文与审核历史，追加保存 |
| `runs` | 操作状态、基准版本、生成候选、审核结果、上下文选择信息、响应 ID 与 token 用量 |

Schema 版本为 `PRAGMA user_version=1`，不认识的版本拒绝打开。数据库与旧 `books/` 文件布局互不兼容，不会自动导入或修改旧数据。

## 一次写章

1. 在短事务中读取一致快照，并创建 `running` 的运行记录。
2. 只允许写下一章；显式 `rewrite` 只允许重写当前阶段的最新一章。避免历史编辑悄悄使后文失效。
3. 使用作品设定、当前阶段、场景规划、前一章摘要与结尾，以及相关事实构造上下文。重写时排除该章旧版本。
4. 生成或接收手写正文，将完整正文交给审核模型。上下文预算不足时失败并保留候选，不截断正文。
5. 本地检查审核契约、验收项顺序、事实标识唯一性、所有证据是否为本章原文连续子串，以及实质矛盾。
6. 开启 `BEGIN IMMEDIATE`，比较 `books.revision`。快照过期则拒绝提交，候选保存到失败运行中。
7. 同一事务内追加历史、替换当前正文及审核、增加书籍版本、将运行标记为成功；重写时同时删除后续未写规划，避免沿用旧正文的推演。

生成期间不持有数据库写锁。跨进程并发通过书籍版本比较阻止丢失更新。模型调用可能已产生费用，即使最后因并发冲突未提交。

失败候选通过 `runs` 可读，修订后使用 `write --file` 重新审核提交。进程被强制杀死时运行可能停留在 `running`，不代表后台仍在执行；没有自动恢复调度器。若强制终止发生在候选入库之前，该内存中的候选无法恢复。普通捕获到的失败会持久化已有候选。

## 规划、记忆和阶段

未来大纲只能从未写章节开始，不能留下编号缺口。重规划删除该起点及其后的旧规划，再写入完整新批次；返回编号、数量或阶段错误时整批拒绝。

事实以 `(kind,key)` 标识：人物状态、已发生事件、伏笔状态。记忆由当前采纳正文的审核结果按章回放，同一标识由后章更新。历史版本不参与记忆，重写移除旧事实，不使用无序集合冒充事件发生顺序。

阶段验收逐项累积当前阶段各章的原文证据，仅采纳该次审核置信度 `>=0.8` 的达成结果。全部达成后仍需要用户显式确认下一阶段的目标和验收项；阶段切换清除未写的大纲。验收条件应描述可累积的剧情里程碑，而非会随时反转的瞬时属性。

原文存在性不等于语义蕴含：模型仍可能错误解读一句真实引文。置信度也只是模型自评。自动审核不能代替作者判断。

## 上下文与成本

世界设定、用户创意、当前阶段和本章任务为必需上下文。上一章摘要及末尾最多 1000 字符也必须容纳。之后按任务词项重合度、活跃伏笔和时序选择事实，再补历史摘要。中文用双字词项，英文按词；这不是 embedding 或语义检索。

`SCRIPTOR_CONTEXT_CHARS` 是上下文字符预算，不是模型 token 上限。审核会为完整正文预留空间，重新选择参考事实；核心信息放不下时明确报错。`runs.artifacts` 记录选择数量与省略数量，可用来检查召回。未检索到的事实可能导致漏检矛盾。

一次设定或规划通常一次模型调用，写章通常两次（正文、审核），手写正文只调用审核；SDK 仅对传输类可重试错误进行有限重试。没有自动反复修文、无限重规划或默认自动写完整本书。没有按厂商价格估算费用，只记录返回的真实 token 用量。

## 验证与限制

测试覆盖事务回滚、并发版本冲突、失败候选保存、重写字数与记忆、阶段证据、全文审核、规划替换、HTTP API 和 CLI。Responses 协议测试经过实际 SDK 的 HTTP 序列化与响应解析，所有模型响应均为离线桩。

当前提供网页编辑器（`/`）、CLI 和 HTTP API（`/docs` 为交互接口文档）。编辑器资源打包在 `scriptor/static/`，由同一 FastAPI 服务提供，浏览器仅调用现有业务接口。未保存草稿按书籍和章节暂存在 localStorage，载入旧版本或候选后仍需重新审核；生成期间锁定交互，跨章节候选恢复校验目标章节是否可编辑。没有流式输出、任务队列、任意历史章节修改、自动修文、向量库或旧书迁移。应用按单机本地工具运行，未实现多用户鉴权。正文长度是生成目标，统计采用字符数，不承诺精确中文词数或文学质量。
