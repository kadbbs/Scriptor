# Scriptor 写作工作台界面

本文记录用户提供的桌面端首页截图。当前界面处于书架为空、尚未选择作品的欢迎状态。截图尺寸为 1908 × 806 像素，页面内容未全部显示。

## 页面结构

页面采用左侧书架、右侧工作区的双栏布局。左栏约占截图宽度的 17%，与主工作区之间以细竖线分隔。

│ S.  Scriptor        │ 写作工作台                 准备就绪  刷新 │
│     故事从这里继续  ├──────────────────────────────────────────┤
│                     │                                          │

│ API 文档 ↗          │    ……下方内容未在截图中完整显示          │

## 左侧书架

| 区域 | 可见内容 | 表现方式 |
| --- | --- | --- |
| 品牌标识 | `S.` | 深绿色衬线字母，放置在细描边圆角方框内 |
| 产品名称 | Scriptor | 深色加粗文字，与标识并排 |
| 品牌副标题 | 故事从这里继续 | 位于产品名称下方，使用较小的灰色文字 |
| 书架标题 | 我的作品 | 位于品牌区域下方 |
| 新建入口 | ＋ | 位于「我的作品」右侧 |
| 空状态提示 | 书架还空着。<br>从一个想法开始吧。 | 分两行居中显示，四周留白 |
| 空间状态 | ● 本地写作空间 | 位于侧栏底部，绿色圆点搭配灰色文字 |
| 文档入口 | API 文档 ↗ | 位于空间状态下方 |

底部空间状态与上方书架之间有一条浅色水平分隔线。

## 顶部工具栏

工具栏横跨右侧工作区，底部有细分隔线。

- 左侧显示当前区域名称：**写作工作台**。
- 右侧显示当前状态：**准备就绪**。
- 最右侧提供 **刷新** 操作，文字颜色更深、字重更高。

## 欢迎区域

欢迎文案位于右侧主区域中部偏左，上方和右侧保留大量空白。

**英文引导语：**

> A SPACE FOR YOUR NEXT CHAPTER

采用全大写、小字号、较宽字间距的灰色文字。

**主标题：**

> 让一个念头，  
> 长成一个世界。

主标题使用大号深绿色中文衬线字体，分两行展示，行距宽松，是页面的主要视觉焦点。

**截图中可见的说明文案：**

> 从设定到场景，从正文到伏笔。

截图底部截断了后续内容，不能据此认为页面没有后续说明或创建按钮。

## 视觉样式

- **整体气质：** 安静、简洁，接近纸张与书籍的阅读体验。
- **页面背景：** 主区域为暖米白，侧栏为浅灰绿色。
- **文字颜色：** 标识和主标题使用深绿色，辅助文字使用低饱和灰色。
- **字体层次：** 主标题和标识使用衬线风格；产品名称与操作文字形成更紧凑的层次。
- **边界处理：** 以浅色细线划分区域，品牌标识和截图外框具有圆角。
- **留白：** 品牌区、书架空状态和欢迎文案之间均有明显间隔。
- **滚动状态：** 截图右侧可见纵向滚动条，首屏未容纳完整欢迎区域。
